# Навигация по каталогу

Выбранная схема: теги и фильтры без обязательной иерархии категорий. Она рассчитана на рост каталога и работу касанием на интерактивной панели. Каталог показывает общий список, который можно уточнить по нескольким признакам; поиск по названию и теме остаётся дополнительным путём.

## Фильтры

- **Класс:** 1–4, 5–8, 9–11, «Уточняется». Рекомендация по классу не блокирует доступ к другим упражнениям. Предварительный класс показывается с пометкой.
- **Тема:** предметная тема задания, например «Дни недели» или «Синтаксис». Не путать с визуальной темой оформления.
- **Формат:** что делает ученик — выбирает ответ, собирает порядок, запоминает, пишет текст, рассматривает схему. У игры может быть несколько форматов.
- **Язык:** русский или русский + казахский. Тег описывает реальные тексты заданий, а не язык браузера.

Внутри одного признака можно выбрать несколько значений: они объединяются по «или». Разные признаки объединяются по «и». Например, «1–4» и «Дни недели» покажут обе игры про неделю; «Выбор ответа» вместе с «Собрать порядок» покажет задания с любым из этих форматов в выбранной теме. Пустой фильтр ничего не ограничивает.

Показывать только значения, встречающиеся в каталоге. Рядом со списком всегда видны число результатов и действие «Сбросить фильтры». При отсутствии результатов показывать понятное сообщение и кнопку возврата ко всем упражнениям. Фильтры должны быть крупными кнопками с заметным выбранным состоянием; только цветом состояние не обозначать, использовать также рамку и `aria-pressed`.

## Теги и метаданные

Словарь тегов централизован в `src/catalog/filtering.js`; названия в карточках и фильтрах берутся из него. Игры получают стабильные идентификаторы признаков через `facets` в `src/games/registry.js`. Не создавать близкие дубли вроде «Синтаксис»/«Грамматика» для одного и того же набора без редакторского решения. При добавлении нового упражнения сначала использовать имеющийся тег, при необходимости расширить словарь и проверить, что он полезен для поиска нескольких заданий.

Каждая игра имеет один или несколько `topic`, `format`, ровно один основной `language` и подходящий диапазон классов. Возрастная метка из `docs/THEMES.md` остаётся источником истины: класс для фильтра должен совпадать с указанной рекомендацией; `unknown` не означает «подходит всем». Визуальная тема (`defaultTheme`) не участвует в поиске.

## Дальнейший рост

При большом количестве тегов оставить на первом экране самые употребимые; редкие показать в раскрываемом блоке «Ещё фильтры». Не прятать всё управление за маленькой иконкой. Если появятся полноценные уроки из нескольких упражнений, они получат отдельный тип карточки и теги, но не нарушат общую схему поиска. Перед добавлением сложной сортировки или рекомендаций проверить, как учитель реально находит задания на панели.
