## Порядок для каждого файла

1. Выписать задания, ответы, объяснения, режимы, правила начисления баллов и RU/KZ-тексты. Уточнить рекомендуемый класс, источник рекомендации и тему по правилам `docs/THEMES.md`; назначить теги по `docs/NAVIGATION.md`.
2. Сопоставить с общими взаимодействиями из `docs/UX.md`; определить необходимые компоненты.
3. Перенести данные в `src/games/<slug>/data.js`, интерфейс — в Vue-компонент. Зарегистрировать игру с ленивой загрузкой.
4. Проверить сценарии на сенсорном экране или touch-эмуляции, клавиатурой и на целевых размерах окна; выполнить `pnpm build`.
5. Только после проверки поменять статус в этой таблице и отметить любые осознанные изменения относительно исходника.

## Сборка и GitHub Pages

Vite собирает каталог и лениво подключаемые игры с хешированными файлами. При повторной публикации браузер сможет использовать неизменившиеся файлы из кэша; это первый уровень инкрементальности. Отдельный выборочный билд по играм пока не нужен. `base: './'` позволяет разместить сборку в подпапке Pages. Workflow `.github/workflows/pages.yml` публикует `dist/` после каждого push в `main`.
