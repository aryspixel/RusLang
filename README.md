# RusLang

Основа будущего каталога тренажёров по русскому языку для сенсорной панели 75″. Девять исходных HTML-файлов описаны в [плане переноса](docs/MIGRATION.md); игры пока не переписаны.

Перед работой прочитайте [AGENTS.md](AGENTS.md), [UX-правила](docs/UX.md), [правила тем](docs/THEMES.md) и [навигацию](docs/NAVIGATION.md).

## Локальный запуск

```sh
pnpm install
pnpm dev
```

Сборка для статического хостинга: `pnpm build`. Выход — `dist/`. В `vite.config.js` используется относительная база для GitHub Pages. Автоматическая публикация пока не настроена.
