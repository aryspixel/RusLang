# Предпочтения озвучки RusLang

Сохранено по просьбе владельца 10 октября 2026 года после работы над «Моей комнатой». Это исходные настройки для похожих рассказов начального уровня; прямые указания пользователя для конкретной записи имеют приоритет.

## Голос, темп и паузы

- Модель — **Silero `v5_5_ru`**, выбранный для текущего рассказа голос — **`kseniya`**. Для похожего аудирования начинай с него; не возвращайся к `xenia` только потому, что он указан по умолчанию в CLI.
- Темп — **`slow`**. Вариант `x-slow` пользователь отверг как слишком медленный. Просьба удлинить паузы не означает просьбу замедлить произнесение слов.
- Между предложениями сейчас **700 мс дополнительной тишины** (`--pause-ms 700`). Между элементами перечисления мебели — **450 мс** (`<break time="450ms"/>`). Эти величины не включают собственные паузы синтезатора.
- Рабочая команда для текущего рассказа: `tts.bat --ssml-file src/games/my-room/story-tts-kseniya.ssml --speaker kseniya --rate slow --pause-ms 700 --output <новый файл.wav>`.

## Произношение и выразительность

- Пользователь исправил ударение: **на столé**, в тексте синтеза — `на стол+е`. Автоударения не заменяют явные исправления владельца; сохраняй их в дальнейших версиях записи.
- Для имени **Алия** пользователь явно указал ударение на последнюю «я»: `Али+я`. Затем имя заменено на **Амину**; текущая техническая разметка — `Ам+ина`. Не переносить ударение одного имени на другое автоматически; при новом указании владельца обновить его во всех вариантах синтеза.
- Нужна живая, эмоциональная речь. Финальная фраза **«Я люблю свою комнату!»** должна звучать с теплом и восклицанием. Пользователь сначала удалил её, затем явно вернул: актуально сохранение фразы.
- Перечисление должно оставаться интонационно незавершённым до последнего элемента: **«стол… стул… шкаф ↗ … и кровать ↘»**. Пользователь отдельно отметил нежелательное снижение тона на «шкаф» и допустимое снижение на «кровать».
- Последний вариант использует `<prosody pitch="high">шкаф,</prosody>` и паузу перед «и кровать». Запятая здесь служебная для синтеза; в обычном учебном тексте её перед одиночным «и» нет. Повышение регистра не гарантирует восходящий контур; этот вариант **ещё не получил подтверждения владельца**. Не объявляй интонацию проверенной или одобренной только по успешному созданию WAV.

## Работа с текстами и правками

Храни обычный рассказ в `story.txt`, явные ударения — в файлах для синтеза, точные паузы и интонационные указания — в отдельном SSML. Учебный текст на экране должен совпадать по словам с записью; служебные `+` и XML не выводятся ученикам.

В этом сценарии текст сначала согласовали с владельцем. Согласованный рассказ не переписывай ради выразительности; ограничивайся запрошенными изменениями и интонационной пунктуацией в версии для синтеза. При изменении имени обновляй также заголовки, вопросы и текстовые файлы. Уже запрошенные конкретные правки не требуют повторного согласования.

Сохраняй остальные выбранные настройки при точечной правке. Предыдущий вариант и его метаданные можно хранить в `.local/silero/archive/`, в игре подключай актуальный WAV. Дай владельцу прослушать результат. Не запускай проверки или дополнительную генерацию при просьбе только запомнить предпочтения.
